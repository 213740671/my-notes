# PPT绘图快捷键学习笔记

## 一、 对象选择与基本操作

| **快捷键**        | **功能**           | **说明**                                           |
| ----------------- | ------------------ | -------------------------------------------------- |
| `Ctrl + A`        | **全选**           | 单击画布空白处可取消选择。                         |
| `Ctrl + 单击对象` | **多选**           | 按住Ctrl键，逐个单击想要选择的对象。               |
| `Ctrl + Z`        | **撤销**           |                                                    |
| `Ctrl + Y`        | **还原**           | 恢复上一步的撤销操作。                             |
| `Ctrl + S`        | **保存**           |                                                    |
| `Ctrl + X`        | **剪切**           |                                                    |
| `F4`              | **重复上一步操作** | 非常高效的快捷键。笔记本电脑可能需要按 `Fn + F4`。 |

## 二、 移动、复制与对齐

| **快捷键**            | **功能**          | **说明**                                                     |
| --------------------- | ----------------- | ------------------------------------------------------------ |
| `方向键`              | **微调位置**      | 使用上/下/左/右键微调对象位置。                              |
| `Ctrl + 方向键`       | **更精细微调**    | 以更小的幅度移动对象。                                       |
| `Shift + 拖动`        | **水平/垂直移动** | 限制对象只能在水平或垂直方向上移动。                         |
| `Alt + 拖动`          | **取消对齐**      | 移动对象时暂时取消自动对齐和吸附功能，实现自由微调。         |
| `Ctrl + 拖动`         | **复制**          | 按住Ctrl拖动一个对象，可以直接复制它。                       |
| `Ctrl + D`            | **等距复制**      | 先复制一个对象并移动到目标位置，之后不断按Ctrl+D，可按相同距离和方向连续复制。 |
| `Ctrl + Shift + 拖动` | **水平/垂直复制** | 在水平或垂直方向上快速复制对象。                             |

## 三、 缩放与旋转

| **快捷键**            | **功能**           | **说明**                                                     |
| --------------------- | ------------------ | ------------------------------------------------------------ |
| `Shift + 缩放`        | **等比例缩放**     | 保证图形（如圆形、正方形、图片）在缩放时维持原有比例不变形。 |
| `Ctrl + 缩放`         | **中心缩放**       | 以对象的中心点为基准进行放大或缩小。                         |
| `Ctrl + Shift + 缩放` | **等比例中心缩放** | 结合了以上两种缩放的优点。                                   |
| `Shift + 方向键`      | **拉伸**           | 对对象进行单方向（纵向或横向）的拉伸。                       |
| `Shift + 旋转`        | **15度旋转**       | 按住Shift拖动旋转控点，每次旋转15度。                        |
| `Alt + 左右方向键`    | **15度旋转**       | 按住Alt，再按左右方向键，可以15度为单位旋转对象。            |

## 四、 组合与格式

| **快捷键**         | **功能**     | **说明**                                   |
| ------------------ | ------------ | ------------------------------------------ |
| `Ctrl + G`         | **组合**     | 将多个选中的对象组合成一个。               |
| `Ctrl + Shift + G` | **取消组合** | 将已组合的对象打散。                       |
| `Ctrl + Shift + C` | **格式复制** | 复制选中对象的格式（颜色、边框、字体等）。 |
| `Ctrl + Shift + V` | **格式粘贴** | 将已复制的格式应用到另一个对象上。         |
