# 硬件电路基础

## 1  电学基础

### 1.1 基本概念

#### ① 电流

```
定义：  电荷在单位时间内通过导体横截面的流动量
字母表示： I
单位： 安培（A）， 1A = 1000mA = 1000000μA = 1000000000nA， 常用：mA、μA 
```
#### ② 电压

```
定义：电场施加在电荷上的力量，使其在电路中移动的能量。
字母表示：U
单位：伏特（V）， 1KV=1000V； 1V = 1000mV = 1000000μV
```

#### ③ 电阻

```
定义： 导体对电流的阻碍作用就叫该导体的电阻
字母表示：R
单位：欧姆（Ω），MΩ、KΩ 等
```

#### ④ 电路

```
通路
短路
短路
```

#### ⑤ 交流电和直流电

```
直流电：电流的方向和大小保持不变
交流电：电流的方向和大小周期性变化
```

#### ⑤ 强电和弱点

```
安全电压：直流：24V； 交流：36V
强电：传输能量的电
弱电：传输信号的电
```

### 1.2 常见定律

#### ① 欧姆定律

```
I = U / R
R = U / I
U = R * I
```

> 先把单位都转为基准单位（V、A、Ω）。

#### ② 功率计算

```
字母表示： P
单位： 瓦特（W）， 1KW = 1000W，1W = 1000mW
```

```
P = U * I
P = I² * R
```

#### ③ 焦耳定律

```
热量表示
字母表示： Q
单位： 焦耳（J）、KJ
```

```
Q = I² * R * t
Q = P * t
Q = U * I * t
```

```
1 度电 = 1 KWh,  是个能量单位
```

#### ④ 串联电路

```R
串联分压
I总 = I1 = I2 ...
R总 = R1 + R2 ....
U总 = U1 + U2 ...
```

#### ⑤ 并联电路

```
并联分流
I总 = I1 + I2 ...
1/R总 = 1/R1 + 1/R2 ...
U总 = U1 = U2 ...
```

### 2.3 电容器

```

   充电、放点；隔直、通交

```

#### ② 常见电容器

## 3 模拟电路 半导体元器件

### 3.1 二极管

#### ① 原理

```
N 型半导体：带自由电子（负电荷）的半导体 
P 型半导体：带空穴（正电荷）的半导体
PN结
```

#### ② 特点和功能

```
单向导通
```

#### ③ LED

```
发光二极管
```

### 3.2 晶体管（三极管）

#### ① 组成

```
B 基极
C 集电极
E 发射极
```

```
NPN 型电流方向： 从基极和集电极流向发射极
PNP 型电流方向： 从发射极流向基极和集电极
```

#### ② 功能

```
1. 开关
2. 信号放大
```

### 3.3 场效应管（mos管）

#### ① 组成

```
栅极 g
漏极 d
源极 s
```

```
nmos(N沟道)： 栅极施加高电平 漏极 -> 源极
pmos（P沟道）：栅极施加低电平 源极 -> 漏极
```

#### ② 功能

```
开关
```
