## 6 速通PCB设计流程（按键点灯）2

**原理图绘制：**

```
1. 放置器件
2. 位号、商品名
3. 旋转器件
4. 绘制导线
5. 非连接标识
6. DRC检查
```

**PCB绘制：**

```
1. 从原理图更新到PCB
2. 器件摆放
3. 2D、3D预览
4. 板框，设置尺寸、圆角
5. 布线
6. 图层管理：顶层、底层； 器件翻面
7. 过孔
8. DRC检查
```

**PCB布线一般原则：**

```
（1）导线间距：5V/mil
（2）走线拐角：不允许出现<90度的角。
（3）走线宽度：高频信号线越宽越好（比如：时钟信号）。
    1A:20mil~40mil
    2A:30mil~50mil
    3A:60mil~100mil
    100mA以下：10mil
（4）过孔数量：一般一根信号线的过孔不要超过3个。
```

## 9 51单片机核心板设计

### 9.1 供电模块

#### ① TypeC 接口

```
1. 外壳两个引脚处理
2. 高速差分信号相关引脚不使用
3. CC引脚通过电阻接地（防止被识别成其他设备）
```

#### ② 自恢复保险丝和滤波电容

```
1. 自恢复保险丝
2. 滤波电容滤除突变电压，输出端是 22μF 电容
```

#### ③ 低压差线性稳压器

```
1. LDO 低压差线性稳压器
2. 输入5v，输出3.6v
3. 输入端 1μF滤，输出端 1μF、10μF、47μF 三级滤波
```

### 9.2 单片机最小系统

#### ① 单片机和供电

```
1. 批量扇出单片机网络标签，导出位excel
2. 供电，电容滤波
```

#### ② 排针

```
批量扇出排针网络标签
```

#### ③ 晶振电路

```
1. 使用无源晶振，连接单片机 XTAL1 和 XTAL2 引脚
2. 晶振外接 20pF 负载电容
```

#### ④ 复位电路

```
1. 单片机的RST引脚，高电平触发复位
2. 利用电容的充放电延长RST引脚高电平的时间
```

#### ④ P0 引脚添加上拉电阻

```
P0引脚使用开漏输出，需要外接上拉电阻
```

### 9.3 烧录模块

#### ① 差分信号转TTL信号

```
1. USB传输的差分信号，MCU需要TTL信号
2. CH340系列芯片可以将差分信号转为TTL信号
```

#### ② 冷启动（硬复位）

```
情况一：数据烧录完毕，自动冷启动； 通过控制稳压电源芯片的en使能信号，如果是0，MCU断点
情况而：硬复位按键按下，自动冷启动； 通过控制稳压电源芯片的en使能信号，如果是0，MCU断点
```

#### 9.4 指示灯

```
电源指示灯： 红灯
发送指示灯： 蓝灯
接收指示灯： 绿灯
P0指示灯：  黄灯
```
