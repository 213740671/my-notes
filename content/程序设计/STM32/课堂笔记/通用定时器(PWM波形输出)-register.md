# 电路原理

TIM5通用定时器  =>  比较输出功能实现PWM方波的输出   完成呼吸灯的效果

LED2 -> PA1 -> TIM5_CH2

# 内部寄存器

**(1) CR1控制寄存器: 计数方向  模式选择  定时器使能**

(2) CR2控制寄存器: 输入1通道是否使用异或   主模式选择   DMA功能

(3) 从模式控制寄存器

(4) DMA/中断使能: 开启DMA或中断功能

(5) SR状态寄存器: 输入输出中断标记    溢出中断

(6) EGR: 事件产生

**(7) CCMR1/2: 通道模式选择寄存器  选择对应的CH2通道为PWM1输出模式**    -> 选择PWM方波输出的通道

**(8) CCER: 捕获比较使能寄存器   ->  开启通道输出   高电平有效**    

**(9) CNT/PSC/ARR: 计数器  预分频器   重装载寄存器**   决定PWM方波的周期/频率

**(10) CCR2比较寄存器: 决定占空比    CCR2/CNT最大值+1**   决定PWM方波的占空比

(11) DMA控制和DMA地址: 对应DMA功能

# 案例实现

## 初始化TIM5

1. 打开时钟 TIM5 PA
2. 配置引脚模式 PA1复用推挽输出
3. 配置时基单元 预分频 重装载的值
4. 选择通道二 设置模式为PWM1输出模式 使能通道 都使用高电平有效
5. CR1设置向上计数 打开使能开关

## 编写软件逻辑实现呼吸灯效果

1. 设计方法 随时修改占空比
2. main方法中 随着时间动态修改占空比

```cpp
uint16_t dutyCycle = 10;
	int8_t step = 1; // 1表示每次增加1   -1表示每次减少1
	while (1)
	{
		if (dutyCycle == 99 || dutyCycle == 1)
		{
			step = -step;
		}
		dutyCycle += step;
		Driver_TIM5_SetDutyCycle(dutyCycle);
		Delay_ms(10);
	}
```
