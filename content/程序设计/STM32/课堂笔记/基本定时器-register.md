# 电路原理

TIM6属于基本定时器  ->  APB1低速外设  36Mhz * 2 

# 内部寄存器

CR1控制寄存器: 

​	(1) 预装载功能: 自动重装载寄存器的值什么时候更新到影子寄存器  ->  默认是及时更新

​	(2) 单脉冲模式: 定时器只触发一次  还是循环触发  -> 默认是循环触发

​	(3) 定时器使能: 开关

​	(4) 其他:更新事件相关

CR2控制寄存器:

​	更新事件的主模式

DMA/中断使能寄存:

​	(1) 开启DMA

​	(2) 开启中断

SR状态寄存器:

​	中断标志位

EGR更新事件寄存器:

​	产生一个更新事件(此处用不到)

CNT计数器寄存器:

​	记录当前定时器累加的值

PSC预分频寄存器:

​	存储时钟预分频的值

ARR自动重装载寄存器:

​	记录需要累加达到的值

# 案例实现

## 初始化TIM6

(1) 打开TIM6时钟

(2) 配置预分频和重装载 => 设置为1s的更新中断

​	72MHz -> 预分频 7200 -1  -> 10000Hz (100us)  -> 重装载 10000-1  ->  1s

(3) 预装载功能   单脉冲功能  (此处不使用)

(4) 开启中断  -> NVIC设置中断优先级  和  使能

(5) 使能定时器

## 中断服务程序

(1) 清除中断标志位

(2)  1s执行1次   -> 运行即可
