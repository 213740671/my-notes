# 电路原理

(1) 从模式的使用

接收命令是从 => 发送命令的是主

从模式的信号输入往往使用的是 => 通道传入的PWM方波信号的上升沿或下降沿

接收到从模式对应的命令 会实现复位功能 => 替代之前使用中断的软件复位

(2) 同时使用两个通道

通道的连线 => 直连和非直连 => 本体指代后位的捕获寄存器 IC1

单独配置**滤波和边沿检测和分频**

## 测量原理

(1) 每次遇到上升沿从模式会自动触发 => 清空CNT的值

(2) 每次遇到上升沿 => 通道1的捕获会自动触发 => 拷贝CNT的值到CCR1 (肯定是先拷贝再清空)

(3) 每次遇到下降沿 => 通道2的捕获会自动触发 => 拷贝CNT的值到CCR2

CCR1 = 周期

CCR2 = 高电平持续时间

占空比 = ( CCR2 + 1) * 1.0 /( CCR1 + 1)

# 内部寄存器

**(1) CR1控制寄存器: 计数方向 模式选择 定时器使能**

**(2) CR2控制寄存器: 输入1通道是否使用异或** 主模式选择 DMA功能

(3) 从模式控制寄存器

(4) DMA/中断使能: 开启DMA或中断功能

(5) SR状态寄存器: 输入输出中断标记 溢出中断

(6) EGR: 事件产生

**(7) CCMR1/2: 通道模式选择寄存器**

**(8) CCER: 捕获比较使能寄存器**

**(9) CNT/PSC/ARR: 计数器 预分频器 重装载寄存器** 决定PWM方波的周期/频率

**(10) CCR2比较寄存器: 决定占空比 CCR2/CNT最大值+1** 决定PWM方波的占空比

(11) DMA控制和DMA地址: 对应DMA功能
