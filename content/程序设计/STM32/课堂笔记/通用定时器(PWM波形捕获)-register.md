# 电路原理

使用输入捕获测量PWM方波的周期和频率:

原理是: 在输入引脚的电路产生上升沿的时候, 定时器会自动将CNT的值存到捕获寄存器中.

## 测量量程

预分频系数决定CNT+1的时间   ->   72MHz  1/72us   -> 通常使用72-1分频系数

自动重装载的值决定 能够加到上限的最大值   65535

量程 取决于CNT+1的时间(1us) 和 能够加到上限的最大值  

1Mhz  到 16hz 

如果接近下限  得到的结果是准的  =>   只是接近溢出  定时器溢出  答案就错了

如果接近上限  得到的结果肯定不准  =>  捕获的CNT=1  => 1MHz    捕获的CNT=2  => 0.5MHz 

​	更换方法测量  =>  修改预分频系数  改小 1/72us  CNT+1    =>  CNT = 72  得到1Mhz   CNT = 144  => 0.5Mhz

​	添加输入信号的预分频器  =>  100   降低了输入信号的频率  等于在测量一个低频信号  自然就准

## 测量原理

(1) 输入捕获连接输入信号 

(2) 设置捕获中断

(3) 判断中断触发的次数

​	第一次触发,清空CNT的值  (不管第几次触发  只要设置了输入捕获   CNT写入到CCR)

​	第二次触发,  此时CCR * CNT+1的时间 = 周期   (不管第几次触发  只要设置了输入捕获   CNT写入到CCR)

# 内部寄存器

**(1) CR1控制寄存器: 计数方向  模式选择  定时器使能**

**(2) CR2控制寄存器: 输入1通道是否使用异或**   主模式选择   DMA功能

(3) 从模式控制寄存器

(4) DMA/中断使能: 开启DMA或中断功能

(5) SR状态寄存器: 输入输出中断标记    溢出中断

(6) EGR: 事件产生

**(7) CCMR1/2: 通道模式选择寄存器   **   

**(8) CCER: 捕获比较使能寄存器  **    

**(9) CNT/PSC/ARR: 计数器  预分频器   重装载寄存器**   决定PWM方波的周期/频率

**(10) CCR2比较寄存器: 决定占空比    CCR2/CNT最大值+1**   决定PWM方波的占空比

(11) DMA控制和DMA地址: 对应DMA功能
