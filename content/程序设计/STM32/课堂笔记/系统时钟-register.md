# 原理

系统滴答定时器  24位向下递减  减到0会触发一个中断

# 寄存器

CTRL 控制状态寄存器: 

​	(1) countFlag: 滴答定时器向下递减减到0  会写标签1

​	(2) clkSource: 时钟源  -> 选择总线时钟 或 总线时钟/8

​	(3) TickInt: 时钟中断 -> 1表示开中断

​	(4) enable: 使能时钟

reload重装载寄存器:

​	如果生成的是一个循环响应的时钟  ->  填写N-1 

​	如果生成的是只响一次的时钟 -> 填写N

value当前值寄存器:

​	存储时钟当前计数的值  ->  不管怎么写  都是清空

校准寄存器: 

​	不需要用户操作
