# 电路原理

TIM1的CH1连接LED3  PA8

使用高级定时器的重复计数器功能  => 计数4 + 1次 => 一次性生成5个PWM方波   

每一次时基单元的CNT计数一周, 重复计数器的值-1. 重复计数器到0之后的下一个CNT周期  会触发重复计数器中断 

=> 关闭掉整个TIM1  

# 内部寄存器

**(1) CR1控制寄存器: 计数方向  模式选择  定时器使能**

**(2) CR2控制寄存器: 输入1通道是否使用异或**   主模式选择   DMA功能

(3) 从模式控制寄存器

(4) DMA/**中断使能**: 开启DMA或中断功能  => **重复计数器也是使用的更新中断  因为默认值是0 所以默认也是CNT一个周期一个中断**

(5) SR状态寄存器: 输入输出中断标记    溢出中断

(6) EGR: 事件产生

**(7) CCMR1/2: 通道模式选择寄存器   **   选择使用输出模式  使用PWM1模式

**(8) CCER: 捕获比较使能寄存器  **    使能通道1 

**(9) CNT/PSC/ARR: 计数器  预分频器   重装载寄存器**   决定PWM方波的周期/频率

**(10) CCR2比较寄存器: 决定占空比    CCR2/CNT最大值+1**   决定PWM方波的占空比

(11) DMA控制和DMA地址: 对应DMA功能

(1) 打开时钟  TIM1 GPIOA8

(2) 配置引脚模式 复用推挽输出

(3) 配置TIM1的时基单元  => 2HZ    =>  PSC 7199   ARR 4999  

(4) 配置通道1   =>  PWM1方波输出    高电平有效   输出使能

(5) 刹车输出总开关  =>  控制OC和OCN反向输出的开关    单独打开

(6) 重复计数器  =>  填4 表示5个周期

​	注意: 一旦启动定时器  会自动判断重装载的值和影子寄存器的值是否一致  如果不一致会自动产生更新事件(中断)

​	手动产生更新事件UG => 清空掉中断标志位  => 之后再打开中断

(7) 打开更新中断  => 设置中断优先级  使能

(8) 打开定时器
