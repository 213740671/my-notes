# 代码
## 直接return
```cpp
#include <bits/stdc++.h>  
using namespace std;  
  
string connect(string x,string y) {  
    return x+y;  
}  
  
int main() {  
    string a,b;  
    cin>>a>>b;  
    cout<<connect(a,b);  
    return 0;  
}
```
## 引用传递
```cpp
#include <iostream>  
#include <string>  
using namespace std;  
void connect(string x,string y,string &z) {  
    z=x+y;  
}  
int main() {  
    string a,b,c;  
    cin>>a>>b;  
    connect(a,b,c);  
    cout<<c;  
    return 0;  
}
```
