# 代码
## 直接return
```cpp
#include <bits/stdc++.h>  
using namespace std;  
  
string connect(string x,string y) {  
    return x+y;  
}  
  
int main() {  
    string a,b;  
    cin>>a>>b;  
    cout<<connect(a,b);  
    return 0;  
}
```
## 引用传递
```cpp
#include <iostream>  
#include <string>  
using namespace std;  
void connect(string x,string y,string &z) {  
    z=x+y;  
}  
int main() {  
    string a,b,c;  
    cin>>a>>b;  
    connect(a,b,c);  
    cout<<c;  
    return 0;  
}
```

>[!note]+ C++函数的参数的传递有两种形式：值传递和引用传递，其中**值传递**的时候一个值的改变并==不会影响==另一个值的改变.但是，**引用传递**的时候，一个值的改变==会影响==另一个值的改变.它们的区别在于是否有==&==
