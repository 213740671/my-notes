# 代码
## 数组方式
```cpp
#include <bits/stdc++.h>  
using namespace std;  
  
int main() {  
    int a[10];  
    for (int i=0;i<10;i++) {  
        cin>>a[i];  
    }  
    for (int i=9;i>=0;i--) {  
        cout<<a[i];  
        if (i!=0)  
            cout<<" ";  
    }  
}
```
## 栈的方式(先进后出)
```cpp
#include <bits/stdc++.h>  
using namespace std;  
stack<int>s;  
  
int main() {  
  
    for (int i=0;i<10;i++) {  
        int a;  
        cin>>a;  
        s.push(a);  
    }  
    for (int i=9;i>=0;i--) {  
        if (s.empty())  
            break;  
        cout << s.top();  
        s.pop();  
        if (i!=0)  
            cout<<" ";  
    }  
}
```
>[!tip]+ 在 C++ 中，stk.pop() 只负责弹出，不返回栈顶元素。如果你想获取栈顶的值并弹出，必须先调用 stk.top()，然后再调用 stk.pop()。
