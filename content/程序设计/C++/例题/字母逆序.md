>[!info]+ getline的应用
> getline能够获取一行所有的字符作为字符串
> 普通cin以空格作为输入结束的标志

# 代码
```cpp
#include<bits/stdc++.h>  
using namespace std;  
  
int main() {  
    string s;  
    getline(cin,s);  
    reverse(s.begin(),s.end());  
    cout<<s<<endl;  
    return 0;  
}
```
