> [!info]+ getline 与 reverse 的应用与注意事项
> **getline(cin, s)**：从输入流中读取“一整行”到字符串 `s` 中，默认以换行符 `\n` 作为结束标记（换行符本身不会被存入 `s`）。它可以读入包含空格的内容，这点与 `cin >> s`（遇到空格就停止）不同。
>
> **常见注意事项**：
>
> - 如果前面使用过 `cin >>` 读取数字/单词，输入缓冲区里往往还残留一个换行符，紧接着 `getline` 可能直接读到空行。通常在 `getline` 前先清理换行：
>   ```cpp
>   cin.ignore(numeric_limits<streamsize>::max(), '\n');
>   ```
> - `getline` 读到的可能是空串（例如用户直接回车），处理前可判断 `s.empty()`。
> - 连续读取多行需要循环调用 `getline`。
>
> **reverse(s.begin(), s.end())**：来自 `<algorithm>`，在原字符串上“就地”反转区间 `[begin, end)` 内的字符，时间复杂度 `O(n)`。
>
> **reverse 的注意事项**：
>
> - 传入的是迭代器区间，写法必须是 `reverse(容器.begin(), 容器.end())`。
> - 它反转的是**字符/元素**序列；对 UTF-8 等多字节编码文本，直接反转 `string` 会按字节反转，可能破坏中文等字符显示（本题为字母/ASCII 输入则没有问题）。

# 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    string s;
    getline(cin,s);
    reverse(s.begin(),s.end());
    cout<<s<<endl;
    return 0;
}
```
