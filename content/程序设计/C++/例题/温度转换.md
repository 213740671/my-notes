# 要点
> cout << fixed << setprecision(2) << "c=" << c << endl; 

`fixed`的作用在于让后面的`setprecision()`函数内的数字表示为小数点后的位数
不加的话则表示总的位数
# 代码
```cpp
#include<bits/stdc++.h>  
using namespace std;  
  
int main() {  
    double f=0,c=0;  
    cin>>f;  
    c=5*(f-32)/9;  
    cout << fixed << setprecision(2) << "c=" << c << endl;  
    return 0;  
}
```
