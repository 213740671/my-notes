# 代码
```cpp
#include<bits/stdc++.h>  
using namespace std;  
  
int main() {  
    int nn;  
    cin>>nn;  
    getchar();  
    string s[nn];  
    for (int i=0;i<nn;i++) {  
        getline(cin,s[i]);  
    }  
    for (int i=0;i<nn;i++) {  
        cout<<s[i]<<endl<<endl;  
    }  
    string v;  
    while (getline(cin,v)) {  
        for (int i=0;i<v.length();i++) {  
            if ((v[i])==' ') {  
                cout<<endl<<endl;  
            }  
            else {  
                cout<<v[i];  
            }  
        }  
        cout<<endl<<endl;  
    }  
    return 0;  
}
```

>[!info]- 知识点
> ## 1) `cin >>` vs `getline` 的区别
> - `cin >> x`：按**空白符**（空格/换行/制表符等）分隔读取；遇到空白符就结束。
> - `getline(cin, s)`：读取**一整行**（直到遇到换行符 `\n`），行内空格会被保留。
>
> ## 2) 混用时的“吞回车”问题（本题关键）
> - `cin >> nn` 读取数字后，输入缓冲区里通常还剩一个换行符 `\n`。
> - 如果紧接着 `getline(cin, s)`，第一次 `getline` 可能读到**空行**（把这个 `\n` 读走）。
> - 解决方式：在 `getline` 前清理掉残留的换行符。
>   - 常见写法 1：`cin.ignore(numeric_limits<streamsize>::max(), '\n');`（更推荐，稳妥）
>   - 常见写法 2：`getline(cin >> ws, s);`（`ws` 会吞掉前导空白符）
>   - 本题代码用 `getchar()` 也能“吃掉一个字符”，但它属于 C 的输入函数，**与 C++ 流混用不够优雅**，且遇到 `\r\n`（Windows）等情况可读性较差。
>
> ## 3) `while (getline(cin, v))` 的含义
> - 这是读取到 **EOF**（文件结束/控制台 Ctrl+Z 后回车）或发生输入失败为止。
> - `getline` 成功返回真；失败（EOF/错误）返回假，因此可作为循环条件。
>
> ## 4) 字符串遍历与类型细节
> - `v.length()` / `v.size()` 返回类型是 `size_t`（无符号）。
> - 更推荐写法：`for (size_t i = 0; i < v.size(); ++i)`，避免有符号/无符号比较警告。
> - 也可以范围 for：`for (char c : v) { ... }`。
>
> ## 5) 把空格替换成换行的思路
> - 本题要求将一行中以空格分隔的单词“拆开输出”，实现方式就是：
>   - 遇到 `' '` 输出两次换行（形成空行）；否则输出原字符。
> - 需要注意：连续多个空格会产生多个空行（是否符合题意取决于题目要求）。
>
> ## 6) 容器选择：`string s[nn]` 的可移植性
> - `string s[nn];` 属于“变长数组”（VLA），**不是标准 C++**（有些编译器当扩展支持）。
> - 标准写法建议：`vector<string> s(nn);`，更安全、可移植。
>
> ## 7) 输出格式
> - `cout << ... << endl;` 会额外刷新缓冲区（更慢）；如果不需要强制刷新，可用 `"\n"`。
> - 本题为了输出空行使用 `endl<<endl`，等价于输出 `"\n\n"`。
