# 代码
```cpp
#include<bits/stdc++.h>  
using namespace std;  
  
int main() {  
    int nn;  
    cin>>nn;  
    getchar();  
    string s[nn];  
    for (int i=0;i<nn;i++) {  
        getline(cin,s[i]);  
    }  
    for (int i=0;i<nn;i++) {  
        cout<<s[i]<<endl<<endl;  
    }  
    string v;  
    while (getline(cin,v)) {  
        for (int i=0;i<v.length();i++) {  
            if ((v[i])==' ') {  
                cout<<endl<<endl;  
            }  
            else {  
                cout<<v[i];  
            }  
        }  
        cout<<endl<<endl;  
    }  
    return 0;  
}
```

>[!info]- 知识点
> getline():用于获取整行内容(即使中间含有空格也会一并获取)[cin会根据空格判断输入结束]
> getchar(用来消除回车符的干扰)
