# C++ 类型转换

在 C++ 中，类型转换分为 **隐式转换 (Implicit Conversion)** 和 **显式转换 (Explicit Conversion)** 两种机制。

---

## 1. 隐式转换 (Implicit Conversion)
由编译器根据上下文自动完成，无需程序员干预。

### 1.1 算术运算 (Usual Arithmetic Conversions)
当不同类型的数值混合运算时，编译器会将它们转换为**精度更高**或**范围更大**的同一类型，防止数据丢失。

*   **原则**：向高精度对齐 (Widening)
*   **优先级链**：
    `int` → `unsigned` → `long` → `double` → `long double`
*   **示例**：
    ```cpp
    int a = 5;
    double b = 2.5;
    auto res = a + b; // a 自动转换为 double，结果 res 为 double 类型 (7.5)
    ```

### 1.2 赋值操作 (Assignment)
当右值赋给左值变量时，右值会转换为左值的类型。

*   **注意**：可能发生精度丢失（截断）。
*   **示例**：
    ```cpp
    double d = 10;    // int(10) -> double(10.0)
    int i = 3.14;     // double(3.14) -> int(3) [精度丢失]
    ```

### 1.3 函数调用与返回
*   **传参**：实参类型自动转换为形参类型。
*   **返回**：return 语句的值自动转换为函数声明的返回类型。

### 1.4 条件判断 (Boolean Context)
非布尔值在 `if`, `while` 等语句中自动转为 `bool`。
*   **数值**：`0` -> `false`, 非 `0` -> `true`
*   **指针**：`nullptr` -> `false`, 非空指针 -> `true`

---

## 2. 显式转换 (Explicit Conversion)
由程序员使用特定操作符强制进行，通常用于处理编译器无法自动解决的转换。

### 2.1 C 风格转换 (C-style Cast)
语法简单但风险较高，不做类型检查。
*   **语法**：`(type)value` 或 `type(value)`
*   **示例**：`(int)3.14`

### 2.2 C++ 风格转换 (C++ Casting Operators)
更安全、意图更明确的转换方式。

| 操作符 | 用途说明 |
| :--- | :--- |
| **`static_cast<T>(expr)`** | **最常用**。用于良性转换（如 int 转 float，子类指针转父类指针）。编译时检查。 |
| **`dynamic_cast<T>(expr)`** | **多态专用**。用于基类和派生类指针/引用间的安全转换。运行时检查，失败返回 `nullptr`。 |
| **`const_cast<T>(expr)`** | **去常量性**。用于移除变量的 `const` 或 `volatile` 属性。 |
| **`reinterpret_cast<T>(expr)`**| **底层重解释**。用于任意类型的指针间转换（如 int* 转 char*），极度危险。 |

---

## 3. 总结图示
> **算术运算规则**：
> * `int` * `float` = `float`
> * `float` * `double` = `double`
> * `int` * `int` = `int` (无转换)
