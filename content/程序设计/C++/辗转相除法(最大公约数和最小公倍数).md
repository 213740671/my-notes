# 学习笔记：辗转相除法 (Euclidean Algorithm)

## 一、 计算方法 (How to calculate)

辗转相除法用于求解两个正整数 $a$ 和 $b$ 的最大公约数 $\text{GCD}(a, b)$。

### 步骤说明：
1.  **相除**：用较大的数 $a$ 除以较小的数 $b$，得到余数 $r$。
2.  **更替**：如果 $r \neq 0$，则令 $a = b$，$b = r$，返回第1步。
3.  **终止**：如果 $r = 0$，则此时的除数 $b$ 即为这两个数的最大公约数。

### 示例：求 GCD(1997, 615)
* $1997 \div 615 = 3 \dots 152$
* $615 \div 152 = 4 \dots 7$
* $152 \div 7 = 21 \dots 5$
* $7 \div 5 = 1 \dots 2$
* $5 \div 2 = 2 \dots 1$
* $2 \div 1 = 2 \dots 0$
* **结果**：最大公约数为 **1**。

---

## 二、 原理解析 (Why it works)

### 1. 从“相减”到“相除”的进化
正如你所直觉发现的，辗转相除法的本质是**辗转相减法**的进阶版。
* **相减法逻辑**：如果 $d$ 是 $a$ 和 $b$ 的公约数，那么 $d$ 也一定是 $a-b$ 的约数。
* **相除法逻辑**：$a \div b$ 得到的余数 $r = a - q \times b$（其中 $q$ 是商）。这相当于从 $a$ 里面一次性减去了 $q$ 个 $b$。



### 2. “最小组成单位”视角 (核心直觉)
我们可以将最大公约数 $d$ 看作是构成数字的**“最小刻度单位”**：
* 假设 $a = m \cdot d$，$b = n \cdot d$（$m, n$ 为整数）。
* 在 $a \div b$ 的过程中：$a = q \cdot b + r$。
* 代入 $d$ 得到：$m \cdot d = q \cdot (n \cdot d) + r$。
* 整理得到：$r = (m - qn) \cdot d$。

**结论**：
由于 $m, q, n$ 都是整数，所以==余数 $r$ 依然是 $d$ 的整数倍==。这意味着**在不断取余的过程中，这个“最小单位” $d$ 始终被保留了下来**。随着数值不断缩小，我们最终会逼近那个最原始的 $d$。

### 3. 数学等价性
辗转相除法的合法性建立在以下定理上：
$$\text{GCD}(a, b) = \text{GCD}(b, a \mod b)$$
这个公式保证了我们在缩小问题的规模时，解（最大公约数）保持不变。

## 三、 C++ 实现 (Algorithm Implementation)

基于你的 C++ 学习背景，这里给出两种常见的实现方式：

### 1. 递归实现 (简洁，符合数学定义)
```cpp
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
```

### 2. 迭代实现 (效率高，避免栈溢出)
```cpp
int gcd(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}
```
