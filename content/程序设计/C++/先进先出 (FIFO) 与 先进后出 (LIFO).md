# C++ 笔记：先进先出 (FIFO) 与 先进后出 (LIFO)

## 1. 概念概述
这两个概念指的是**数据结构**中数据的**存储与访问逻辑**。在 C++ 标准模板库 (STL) 中，它们分别对应 **队列 (Queue)** 和 **栈 (Stack)** 两种容器适配器。

---

## 2. 先进先出 (FIFO - First In, First Out)

### 核心逻辑
* **定义**：最先存入的数据，最先被取出。
* **对应容器**：**队列 (`std::queue`)**
* **生活类比**：**排队买票**。先排队的人先买完离开，后排队的人只能排在后面。
* **数据流向**：**双端操作**。数据从队尾（Back）进入，从队头（Front）移出。

### C++ 实现 (`std::queue`)
* **头文件**：`#include <queue>`
* **常用操作**：
    * `push(x)`: 在队尾添加元素 `x`。
    * `pop()`: 移除队头元素（不返回该元素）。
    * `front()`: 获取/访问队头元素。
    * `back()`: 获取/访问队尾元素。
    * `empty()`: 判断队列是否为空。
    * `size()`: 获取队列大小。

---

## 3. 先进后出 (LIFO - Last In, First Out)

### 核心逻辑
* **定义**：最后存入的数据，最先被取出。
* **对应容器**：**栈 (`std::stack`)**
* **生活类比**：**弹夹装子弹**或**叠盘子**。最后放上去的盘子在最顶端，必须先拿走它才能拿到下面的。
* **数据流向**：**单端操作**。数据的进入和移出都在**栈顶（Top）**进行。

### C++ 实现 (`std::stack`)
* **头文件**：`#include <stack>`
* **常用操作**：
    * `push(x)`: 在栈顶压入元素 `x`。
    * `pop()`: 移除栈顶元素（不返回该元素）。
    * `top()`: 获取/访问栈顶元素（**注意：这里叫 top 不叫 front**）。
    * `empty()`: 判断栈是否为空。
    * `size()`: 获取栈大小。

---

## 4. 快速对比表

| 特性 | 先进先出 (FIFO) | 先进后出 (LIFO) |
| :--- | :--- | :--- |
| **容器名称** | **Queue (队列)** | **Stack (栈)** |
| **头文件** | `<queue>` | `<stack>` |
| **进出规则** | 队尾进，队头出 | 栈顶进，栈顶出 |
| **访问首个元素** | `q.front()` | `s.top()` |
| **主要应用** | 任务调度、广度优先搜索 (BFS)、缓冲池 | 函数递归调用、表达式求值、深度优先搜索 (DFS) |

---

## 5. 代码示例

### 队列 (FIFO) 演示
```cpp
#include <iostream>
#include <queue>

using namespace std;

int main() {
    queue<int> q;
    
    // 1. 入队 (Push)
    q.push(10); // 第一个进
    q.push(20);
    q.push(30); // 最后一个进

    // 2. 访问队头 (Front)
    cout << "队头元素: " << q.front() << endl; // 输出 10

    // 3. 出队 (Pop)
    q.pop(); // 移除了 10

    cout << "新的队头: " << q.front() << endl; // 输出 20
    
    return 0;
}
```

### 栈 (LIFO) 演示
```cpp
#include <iostream>
#include <stack>

using namespace std;

int main() {
    stack<int> s;

    // 1. 入栈 (Push)
    s.push(10); // 第一个进，压在最底
    s.push(20);
    s.push(30); // 最后一个进，在最顶

    // 2. 访问栈顶 (Top)
    cout << "栈顶元素: " << s.top() << endl; // 输出 30

    // 3. 出栈 (Pop)
    s.pop(); // 移除了 30

    cout << "新的栈顶: " << s.top() << endl; // 输出 20

    return 0;
}
```
