# 学习笔记：素数判断算法的边界逻辑与优化

### 1. 核心困惑：循环边界的选择
在判断整数 $i$ 是否为素数时，内层循环 `for(int j = 2; j < [边界]; j++)` 的边界设定至关重要。

* **为什么不能用 `j <= i`？**
    * **数学逻辑**：素数定义是只能被 1 和自身整除。
    * **编程后果**：当 `j` 增加到 `i` 时，$i \pmod i$ 必定等于 $0$，导致 `flag` 永远被设为 1（非素数）。这样程序会过滤掉所有数字，包括真正的素数。

* **为什么 `j < i - 1` 也是正确的？**
    * **数学原理**：对于任何 $i > 2$ 的整数，其最大的潜在因数（除去自身外）绝不会是 $i-1$。
    * **证明**：$i \div (i-1) = 1 \dots 1$。因为余数始终为 1，所以 $i-1$ 永远无法整除 $i$。
    * **结论**：在循环中检查到 $i-2$ 还是 $i-1$ 结果是一样的。

---

### 2. 关键知识点总结

| 边界写法 | 是否正确 | 评价 |
| :--- | :--- | :--- |
| `j <= i` | **错误** | 会把所有数都判定为合数。 |
| `j < i` | **正确** | 最符合直觉的标准写法，排除自身。 |
| `j < i - 1` | **正确** | 逻辑可行，但由于 $i-1$ 必不整除 $i$，这一步检查是多余的。 |
| `j * j <= i` | **正确且高效** | **推荐写法**。利用因数的对称性，极大减少运算次数。 |

---

### 3. 进阶：平方根优化的原理
如果一个数 $i$ 是合数，它必然可以分解为 $i = a \times b$。
* 如果 $a$ 和 $b$ 中有一个大于 $\sqrt{i}$，则另一个必然小于 $\sqrt{i}$。
* 因此，我们只需要检查到 $\sqrt{i}$（即 `j * j <= i`）。如果到这里都没找到因数，后面也绝不可能找到了。



### 4. 代码避坑指南
1.  **特判 1**：1 既不是素数也不是合数，程序应从 2 开始处理。
2.  **效率意识**：对于较大的 $nn$（如 $10^5$ 以上），必须使用 `j * j <= i` 或筛法（如埃氏筛），否则程序运行会非常缓慢。
