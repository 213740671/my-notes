# C++ 引用与指针深度解析 🚀

关于您提到的函数参数中 `&` 符号的作用，以及它与指针和 C 语言的区别，请参考下表：

---

## 1. 加 `&` 与不加 `&` 的核心区别 🛠️

在 C++ 函数定义中，`&` 符号决定了参数是“值”还是“别名”。

| 特性 | 值传递 (不加 `&`) | 引用传递 (加 `&`) |
|---|---|---|
| **代码示例** | `void func(string z)` | `void func(string &z)` |
| **底层原理** | 创建参数的副本（拷贝一份新数据） | `z` 成为原变量的“别名”（共享内存） |
| **修改结果** | 函数内的修改**不会**影响原变量 | 函数内的修改**会直接改变**原变量 |
| **内存开销** | 较大（尤其是长字符串或大对象） | 极小（不产生副本） |

---

## 2. 指针 (`*`) 与 引用 (`&`) 的异同 🔍

您提到的 `*` 确实是定义指针的符号。在 C++ 中，引用和指针都能实现修改外部变量的目的，但用法上有别。

| 特性比较 | 引用 (`&`) | 指针 (`*`) |
|---|---|---|
| **定义语法** | `string &z` | `string *z` |
| **函数内使用** | 像普通变量一样用：`z = "..."` | 需要解引用：`*z = "..."` |
| **调用时写法** | 直接传变量名：`connect(a, b, c)` | 需取地址：`connect(a, b, &c)` |
| **安全性** | 必须初始化，不能为空，更安全 | 可以为 NULL，存在野指针风险 |

---

## 3. C 语言与 C++ 的本质不同 🇨 | 🇨++

这是编程语言进化带来的差异：

*   **C 语言**：**没有引用**的概念。如果你想在函数内部修改外部变量，**必须**使用指针 (`*`)。
*   **C++ 语言**：在保留了 C 语言所有指针特性的基础上，**新增了引用**。
*   **现状**：在现代 C++ 开发中，除非需要处理底层内存或实现特定的数据结构，否则程序员通常优先使用**引用**，因为它的语法更自然且不易出错。

---

## 总结结论 📝

在这段代码中，`string &z` 的作用就是为了让函数拼接后的结果能**直接写回**到 `main` 函数的变量 `c` 中。如果不加 `&`，`main` 函数里的 `c` 依然会是空的。
