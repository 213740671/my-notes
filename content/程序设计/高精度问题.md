# 大整数加法

1. **输入两个高精度整数**
   - 用 `string s1, s2` 读入两个可能非常大的数字（避免溢出）。

2. **将字符串转换为倒序整数数组**
   - 调用 `strtoint(s, a[])`：
     - 从字符串末尾开始取每一位字符。
     - 转成数字后按倒序存入数组：
       - 最低位存到 `a[1]`，次低位存到 `a[2]` ……  
     - 这样便于从低位到高位逐位相加（模拟手算加法）。

3. **确定结果数组需要的长度**
   - `len1 = s1.size()`，`len2 = s2.size()`
   - `len3 = max(len1, len2) + 1`
     - 多预留 1 位用于处理最高位可能出现的进位。

4. **逐位相加并处理进位**
   - 对 `i = 1 ... len3` 进行循环：
     - `c[i] = a[i] + b[i] + c[i]`（当前位相加 + 上一轮留下的进位）
     - `c[i+1] = c[i] / 10`（计算进位并存到下一位）
     - `c[i] = c[i] % 10`（当前位保留个位数）

5. **去掉最高位多余的 0**
   - 若最高位没有产生进位（`c[len3] == 0`），则 `len3--`，避免输出前导 0。

6. **输出结果**
   - 因为结果数组 `c` 也是倒序存储的，所以从 `len3` 到 `1` 逆序输出，得到最终高精度加法结果。

```cpp
#include <iostream>
using namespace std;

string s1,s2;//高精度数
int a[101],b[101];//存储高精度数转化后的整数的数组
int c[101];//存储结果的数组

  

void strtoint(string s,int a[]){
    int len=s.size();
    for(int i=1;i<=len;i++){
        a[i]=s[len-i]-'0';//将字符串倒序存储到数组中
    }
}



int main(void) {

    cin>>s1>>s2;
    strtoint(s1,a);
    strtoint(s2,b);

    int len1=s1.size();
    int len2=s2.size();
    int len3=max(len1,len2) + 1;

    for(int i=1;i<=len3;i++){
        c[i]=a[i]+b[i]+c[i];//对应位相加   4321
        c[i+1]=c[i]/10;//进位            765
        c[i]=c[i]%10;//当前位取模         1081  
        }

    if(c[len3]==0 & len3 >1){//最高位是否为0
        len3--;
    }

    //输出最后结果
    for(int i=len3;i>=1;i--){
        cout<<c[i];
    }
    
    return 0;

}
```
# 大整数减法

```cpp
#include<bits/stdc++.h>
using namespace std;

//高精度减法
string s1,s2;
int a[210],b[210],c[210];

void toint_reverse(string s,int t[]){
    for(int i=0;i<s.length();i++)
        t[s.length()-i]=s[i]-'0';
}

int main(){
    cin>>s1>>s2;

    //1.将字符串s转换为整型反转（个位对齐）到整型数组中
    toint_reverse(s1,a);  toint_reverse(s2,b);
    int la=s1.length(),lb=s2.length(),lc=max(la,lb);

    //2.对位相减
    for(int i=1/*从个位开始*/;i<=lc;i++){
        if(a[i]<b[i]){
            a[i+1]--;//借位
            a[i]+=10;//借1当10
        }
        c[i]=a[i]-b[i];
    }
    
    //3.去除前导0 （排除000...000+000...000=000...000的情况）
    while(c[lc]==0&&lc>1)lc--;
    
    //4.倒序打印
    for(int i=lc;i>=1;i--) cout<<c[i];
    return 0;
}
```
