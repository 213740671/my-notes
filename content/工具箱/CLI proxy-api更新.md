### 📝 **更新前的准备**

在执行任何更新操作之前，**强烈建议你先备份最重要的配置文件**，以防万一。

*   **备份 `config.yaml` 文件**：这个文件包含了你的所有个性化配置，如 API 密钥、端口等。请务必复制一份到安全的位置。

---

### 🚀 **更新步骤**

请按照以下命令顺序操作，即可完成项目更新。

| 步骤 | 命令 | 说明 |
| :--- | :--- | :--- |
| **1. 进入项目目录** | `cd CLIProxyAPI` | 首先，你需要进入当初通过 `git clone` 创建的项目文件夹。 |
| **2. 拉取最新代码** | `git pull` | 这条命令会从 GitHub 仓库拉取最新的项目代码。 |
| **3. 重新运行部署脚本** | `bash docker-build.sh` | 再次运行你初次安装时使用的脚本。 |
| **4. 选择部署选项** | *(在脚本提示后输入)* `1` | 和初次部署一样，选择选项 **1**。该脚本会自动从 Docker Hub 拉取最新的预构建镜像，并使用 `docker compose up -d` 命令重新启动服务。 |
| **5. 查看日志确认** | `tail -f ./logs/main.log` | 服务启动后，你可以通过查看实时日志来确认程序是否正常运行。 |

---

### 💡 **重要提示**

*   **检查重大变更**：在更新后，如果遇到任何问题，建议前往 `CLIProxyAPI` 的 GitHub 项目页面，查看最新的发布说明（Release Notes）或提交记录。开发者有时会发布包含重大变更（Breaking Changes）的更新，可能需要你相应地修改 `config.yaml` 配置文件。
*   **配置文件**：`git pull` 命令通常不会覆盖你的 `config.yaml` 文件（因为它不在版本库的跟踪范围内），但备份总是一个好习惯。

完成以上步骤后，你的 `CLIProxyAPI` 就更新到最新版本了。
